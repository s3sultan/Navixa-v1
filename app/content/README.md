# نظام محتوى NAVIXA الرسمي

هذا المجلد هو المرجع المنظم للنصوص الثابتة، وأزرار الإجراءات، والرسائل الديناميكية، وهوية اللغة في NAVIXA.

```text
app/content/
├── ar.ts                 # النصوص الثابتة العربية
├── en.ts                 # النصوص الثابتة الإنجليزية
├── languages.ts          # اتجاه اللغة والـ locale والسهم
├── catalog.ts            # معرفات المحتوى والتصنيفات للمراجعة
├── cta/
│   ├── ar.ts             # أزرار عربية موحدة
│   └── en.ts             # أزرار إنجليزية موحدة
├── messages/
│   ├── ar.ts             # قوالب ديناميكية عربية
│   └── en.ts             # قوالب ديناميكية إنجليزية
└── archive/              # نسخ وفهارس محفوظة قبل أي إعادة صياغة
```

## القاعدة الأساسية

| النوع | مكانه | مثال |
| --- | --- | --- |
| نص ثابت | `ar.ts` أو `en.ts` | `smartListening.readyTitle` |
| زر ثابت | `cta/ar.ts` أو `cta/en.ts` | `watchTutorial` |
| عبارة تعتمد على بيانات حقيقية | `messages/ar.ts` أو `messages/en.ts` | `tasks.overdue(count)` |
| اتجاه ورمز لغة | `languages.ts` | `ar.direction` و`ar.arrow` |
| معرف مراجعة وتصنيف | `catalog.ts` | `plus.heroTitle` و`privacy.description` |

لا تضع اسمًا، أو وقتًا، أو مكانًا، أو عددًا، أو نتيجة، أو حالة جلسة داخل `ar.ts` أو `en.ts`. استخدم قالبًا من `messages` أو دالة محلية قريبة من مصدر البيانات.

```ts
// ثابت
smartListening: { readyTitle: "ينبهك عندما يسمع اسمًا يهمك" }

// ديناميكي: الاسم يأتي من حدث الاستماع الحقيقي
arMessages.smartListening.detectedName(name)
```

## التصنيفات

القيم الموجودة في `catalog.ts` تستخدم أحد التصنيفات التالية: `marketing` و`ui` و`notification` و`dynamic` و`privacy` و`subscription` و`error` و`success`.

إذا كان المطلوب مثل «راجع لغة الاشتراك»، ابدأ من كل المعرفات ذات التصنيف `subscription`. وإذا كان المطلوب «غيّر تنبيه الاسم»، راجع `smartListening.detectedName` في الرسائل الديناميكية، لا القاموس الثابت.

## تعديل نص

عدّل القيمة فقط داخل الملف المناسب، ولا تغيّر اسم المفتاح إن كان مستخدمًا في الواجهة. تحفظ النسخ السابقة وفهرس مواضع النصوص في `archive/` حتى لا تضيع العبارات الأصلية قبل اعتماد صياغة جديدة.

بعد حفظ التعديل على فرع `master`، يمر عبر الاختبارات والنشر التلقائي ثم يصل إلى الموقع عند نجاح سير النشر.
