# قاموس NAVIXA الرسمي للنصوص

هذا المجلد هو المصدر الوحيد للنصوص **الثابتة** التي تظهر في واجهة NAVIXA.

| اللغة | الملف | الاستخدام الحالي |
| --- | --- | --- |
| العربية | `ar.ts` | الواجهة العربية الأساسية. |
| الإنجليزية | `en.ts` | قاموس موازٍ جاهز عند تفعيل واجهة اللغة الإنجليزية. |

## قاعدة مهمة

ضع في القاموس النص الذي لا يتغير بين المستخدمين، مثل عنوان بطاقة، وصف ميزة، أو زر ثابت.

```ts
label: "سماع نداء الاسم"
```

ولا تضع أي عبارة تتكون من بيانات نظام أو مستخدم، مثل الاسم أو الوقت أو المكان أو النتيجة أو عدد المهام. تبقى هذه داخل المكوّن أو داخل دالة ديناميكية قريبة منه.

```ts
const listenerHeardTitle = (name: string) => `تم سماع ${name}`;
```

## طريقة تعديل عبارة

عدّل القيمة النصية فقط داخل `ar.ts` أو `en.ts`. لا تغيّر اسم المفتاح إذا كان مستخدمًا في مكوّنات الواجهة. بعد الحفظ على فرع `master` يبدأ النشر التلقائي، وتصل العبارة الجديدة إلى الموقع بعد نجاحه.

## الأقسام

يُنظم القاموس حسب: NAVIXA، الرئيسية، المهام، التنبيهات، الاستماع، متابعة الشاشة، الإنتاجية، الصحة، الماء، العبادة، الصلاة، المساعد، الاجتماعات، Plus، الخصوصية، الرسائل العامة، والحساب.
