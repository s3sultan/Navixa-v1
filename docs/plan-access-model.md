# NAVIXA plan access model

Effective for the September 2026 launch:

- Trial: free, limited access to the full NAVIXA experience during the launch trial window. Heavy services must remain quota-controlled.
- عَزْم: free features plus screen monitoring and name-call detection only.
- هِمّة: full NAVIXA feature access and included NAVIXA projects, subject to fair-use/service quotas where configured.

Launch trial window: 2026-09-05 through 2026-09-12 16:00 Asia/Riyadh. Subscription reminder begins 2026-09-09.

Operational rule: usage quotas and trial dates should be admin-configurable as backend controls are introduced, so resource-heavy AI/transcription/summarization capacity can be protected for paying هِمّة subscribers without code changes.
