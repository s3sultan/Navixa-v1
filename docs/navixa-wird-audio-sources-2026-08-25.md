# مصادر تلاوة ورد NAVIXA

- Quran.com يعرض تلاوات بندر بليلة على https://quran.com/en/reciters/160 وياسر الدوسري على https://quran.com/en/reciters/174.
- واجهة Quran.com أعادت رابط سورة الفاتحة لبندر بليلة من: https://api.quran.com/api/v4/chapter_recitations/160/1
- واجهة Quran.com أعادت رابط سورة الفاتحة لياسر الدوسري من: https://api.quran.com/api/v4/chapter_recitations/174/1
- توثيق Audio API: https://api-docs.quran.foundation/docs/sdk/javascript/audio/
- الهدف الفني بعد تصحيح المتطلب: تشغيل آيات صفحة المصحف المعروضة فقط، وبترتيبها، لا تشغيل السورة كاملة.
