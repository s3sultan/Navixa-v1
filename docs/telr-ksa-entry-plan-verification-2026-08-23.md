# تحقق عرض Telr السعودي — باقة Entry

**تاريخ المرجع:** 23 أغسطس 2026، بتوقيت السعودية.  
**المصدر:** صفحة تسعير Telr السعودية، وشروط Telr السعودية، ووثائق التكامل الرسمية.

| البند | ما تنص عليه المصادر الرسمية |
|---|---|
| الباقة | Entry Plan لحجم شهري من 0 إلى 30,000 ر.س. |
| الرسم الشهري | 99 ر.س شهريًا. |
| بطاقات الائتمان | 3% + 1 ر.س لكل معاملة، وفق جدول التسعير. |
| مدى | 1% لكل معاملة، وفق جدول التسعير. |
| STC Pay | 0.90% لكل معاملة، وفق جدول التسعير. |
| urpay | 0.80% لكل معاملة، وفق جدول التسعير. |
| VAT | جميع الرسوم المذكورة خاضعة لضريبة القيمة المضافة 15%. |
| رسوم البنك | قد تختلف رسوم إعداد البنك ورسومه الشهرية بحسب البنك. |
| المتطلب المعلن | الرخصة/السجل التجاري إلزامي. |
| الاستمرار والإلغاء | الاتفاق يستمر حتى ينهيه التاجر أو Telr؛ ويجوز للتاجر الإنهاء في أي وقت بإغلاق حساب Telr. لا يظهر حد أدنى معلن لمدة 6 أو 12 شهرًا في الشروط المنشورة. |
| الفاتورة الشهرية | تبدأ الرسوم بعد إشعار اعتماد الحساب وجاهزيته للمعالجة الحية؛ ووفق الشروط تُستحق الرسوم الشهرية في اليوم الأول من الشهر من بطاقة العمل أو الفاتورة/رصيد الحساب. |
| الاسترداد | لا تُسترد رسوم معاملات Telr عند استرداد العميل أو الاعتراض أو رفض المعاملة بحسب نص الشروط. |
| تكامل الاشتراكات | الوثائق تعرض Hosted Payment Page وStored Cards وRepeat Billing وWebhooks؛ التفعيل العملي يستلزم اعتماد الحساب ومفاتيح الجهة. |

> **القرار التشغيلي:** يمكن تجهيز محول Telr في NAVIXA بوضع معطّل، لكن لا يجوز تشغيل تحصيل حي أو فتح Checkout أو إدخال المفاتيح قبل اعتماد التاجر، قبول العرض، وتأكيد المستخدم النهائي.
